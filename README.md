## Sobre o site

Fiz o portfólio com HTML, CSS e JavaScript. Ele tem temas claro e escuro, busca e filtros nos projetos e uma lâmpada amarelinha que acompanha a navegação. Quem curtir pode deixar um like sem precisar criar conta.

A hospedagem fica na Cloudflare. Para o contador de curtidas, usei um Worker com Durable Object e SQLite.
